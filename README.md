# camsim

ブラウザ (WebGL2) で動くカメラシミュレーター。ローポリの街の中にカメラを置いて、焦点距離・F値・シャッター速度・ISO・センサーを変えたときの写りを確認できる。

現在は PoC で、シーンは都市のみ (晴れ / 曇り / 夜)。

## 開発

```sh
npm install
npm run dev     # http://localhost:5173
npm test        # 露出・センサー・光学計算のユニットテスト
npm run build   # dist/ に出力
```

`main` に push すると GitHub Actions (`.github/workflows/deploy.yml`) が GitHub Pages にデプロイする。
初回だけリポジトリの Settings → Pages → Source を「GitHub Actions」にしておく。

## 操作

- ドラッグ: 向き / WASD: 移動 / E・Q: 上下 / Shift: 速く / ホイール: 前後 / クリック: AF
- Enter または「撮影」: 薄レンズ + 露光時間のサンプリングで正確なボケ・動体ブレ・手ブレを描く
- 「等倍表示」: センサー 1 画素 = 画面 1 画素で中央を切り出す (ノイズ・DR の差はここで見る)
- 「RAW 露出補正」: 現像時に持ち上げて暗部ノイズ (= ダイナミックレンジ) を比べる

## シミュレーションの仕組み

```
シーン描画 (物理単位: lx / cd / cd/m², 露出係数を先に掛けた線形 HDR)
  → ライブビュー: 深度からの gather DoF (近似)
    撮影       : レンズ開口上・露光時間内でカメラをずらして N 回描画し平均 (正確)
  → センサー: 光電子数 = RAW × 白の電子数、ショット + 読み出し + 量子化ノイズ、フルウェル / ADC で飽和
  → 現像: RAW 露出補正 → sRGB
```

| 項目 | 実装 | ファイル |
|---|---|---|
| 露出 | ISO 12232 飽和基準。Sunny 16 でテスト済み | `src/camera/sensor.ts` |
| センサー | 画素ピッチ ← センサーサイズ・画素数、フルウェル ∝ 画素面積、読み出しノイズは世代別 (ゲイン前 / 後) | `src/camera/sensor.ts` |
| ボケ | 錯乱円 c = f²S / (N(S−f)) · \|1/S − 1/d\| | `src/camera/optics.ts`, `src/render/shaders.ts` |
| 撮影 | 非対称フラスタムの薄レンズ + 時間サンプル + 絞り羽根形状 | `src/render/lensSampler.ts` |
| 光源 | 太陽 / 半球光 / 街灯 (PointLight) / 発光マテリアルを物理値で設定 | `src/scene/environment.ts` |

縮小表示では 1 表示画素に k 個のセンサー画素が含まれるため、ノイズを 1/√k に平均化している (縮小時の見え方と同じ)。

## PoC の制約・今後

- シーンは都市のみ。室内・野山は未実装
- 実光源 (PointLight) の街灯は中心付近の 24 灯のみ。それ以外は発光体だけ (forward レンダリングのため)。灯数を増やすなら `WebGPURenderer` + `ClusteredLighting`、またはライトマップのベイクに移行する
- 間接光は半球光の近似のみ (AO・GI なし)。曇天や室内は平坦に見える
- ライブビューのボケは近似 (最大半径 48px、前ボケの縁は不正確)。正確な結果は「撮影」で得る
- デモザイク、色ノイズの相関、ノイズリダクション、回折、ビネットは未実装
